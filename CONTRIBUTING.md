# 🤝 Contributing to Raptor RTO

First off, thanks for taking the time to contribute! 🐺

## 📋 Guidelines

### Reporting Bugs
- Check if the issue already exists
- Use the bug report template
- Include screenshots if possible

### Suggesting Features
- Be clear about the feature
- Explain why it would be useful for Ghost Recon/Watch Dogs players

### Pull Requests
1. Fork the repo
2. Create a branch (`git checkout -b feature/name`)
3. Commit changes
4. Push to branch
5. Open a PR

## 💬 Questions?
Open an issue with the label `question`
